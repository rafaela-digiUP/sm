# Vídeos do feed (4:5, 1080×1350, 7 s em loop)

- `digiup-feed-8-video.mp4` — «Digital que cria valor.»: só o círculo vermelho se desenha à volta de «Fale-nos do seu desafio».
- `digiup-feed-9-video.mp4` — «Pessoas primeiro.»: só a esfera vermelha se move (deriva em oito, respiração e ponto quente a girar).

Gerados a partir de `../carrossel.html` com `node render-anim.js <pasta com carrossel.html>` (30 fps, fotograma a fotograma) e codificados com ffmpeg (H.264, faixa de áudio muda para compatibilidade).
